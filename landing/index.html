How it works

Towers, upgrades between waves, a base to hold. Standard tower defense so far.

Nobody built the map. It is streamed from Google's Photorealistic 3D Tiles for whatever address you type in, and three things read that geometry straight off: where the enemies walk, what a tower can see, and where you are allowed to build.

Routes follow real streets

The street graph comes from OpenStreetMap, the thin yellow lines in the picture. The cyan patches are building footprints from the same source. Ground enemies take the red route along those streets, flyers the magenta one straight across. Every waypoint of the ground route is raycast down onto the tile surface for its height, so it follows the actual terrain.

Buildings block line of sight

A tower only fires at what it can see. The surrounding tiles are rendered into a cubemap once, the depth is read back, and the result is kept as a visibility mask over the tower's range. Green cells are covered, red ones are blocked by a building.

Placement probes the ground

Towers are set by raycasting against the tiles, not against a flat plane. Rooftops, embankments and bridges sit at their real height, which is why the same layout plays differently two streets over.

Places

Anywhere Google has photorealistic 3D coverage works, most large cities and a good many smaller ones. How well it plays depends on where you point it. Some places load beautifully, others have tile geometry that makes the routing do slightly silly things.

Get a Cesium ion token

The 3D tiles are billed per request, so there is no shared key. You play on your own Cesium ion token; the free tier is enough.

  1. 1Sign up at ion.cesium.com. Free, no card.
  2. 2Copy your default token under Access Tokens.
  3. 3Paste it into the game when it asks. Once per browser.

The token stays in your browser and is sent only to Cesium. It never reaches this site. A Google Maps API key works too.

The stack

Interface
Angular, standalone components, signal stores
Rendering
Three.js, custom shaders, post processing
Tiles
3DTilesRendererJS over Google Photorealistic 3D Tiles
Map data
OpenStreetMap streets and building footprints, Nominatim lookup
Pathfinding
route grid per location, solved in a web worker
Line of sight
depth cubemap per tower, read back as a visibility mask
Enemies
instanced meshes, skeletal animation baked into vertex textures
Waves
rule based director in the browser, PPO experiment trained offline in PyTorch
Server
none, the client is the whole game
