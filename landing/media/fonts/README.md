# Fonts

Three families, all under the SIL Open Font License 1.1. They are self-hosted so
the landing page loads without a single third-party request, which is also what
keeps the privacy line in the footer true.

The OFL requires the licence and the copyright notice to travel with the font
files, hence the three text files next to them.

| File | Family | Copyright | Licence | Source |
|------|--------|-----------|---------|--------|
| `oswald-var.woff2` | Oswald (variable, 400 to 700) | 2016 The Oswald Project Authors | [OFL-Oswald.txt](OFL-Oswald.txt) | https://github.com/googlefonts/OswaldFont |
| `inter-tight-var.woff2` | Inter Tight (variable, 100 to 900) | 2022 The Inter Project Authors | [OFL-InterTight.txt](OFL-InterTight.txt) | https://github.com/rsms/inter-tight |
| `jetbrains-mono-400.woff2` | JetBrains Mono (400) | 2020 The JetBrains Mono Project Authors | [OFL-JetBrainsMono.txt](OFL-JetBrainsMono.txt) | https://github.com/JetBrains/JetBrainsMono |

The files carry the Latin subset only, the page is English. Reserved Font Names
are untouched: the files keep the original family names, so nothing here counts
as a Modified Version under the OFL.
